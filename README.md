# 🚦 ITS Traffic Dashboard

Sistem deteksi dan penghitungan kendaraan berbasis Computer Vision menggunakan **YOLOv11**, **ByteTrack**, dan **Virtual Line Counting**. Sistem dibangun dengan **Python** dan **Streamlit** untuk mendeteksi, melacak, serta menghitung kendaraan secara otomatis dari video lalu lintas.

## ✨ Fitur

- 🚗 Deteksi kendaraan menggunakan YOLOv11
- 🆔 Pelacakan objek menggunakan ByteTrack
- 📏 Penghitungan kendaraan menggunakan Virtual Line Counting
- 📊 Dashboard interaktif berbasis Streamlit
- 📈 Grafik jumlah kendaraan per interval waktu
- 📄 Ekspor hasil ke file CSV
- 🎥 Simpan video hasil deteksi

## 🛠️ Teknologi

- Python
- Streamlit
- Ultralytics YOLOv11
- ByteTrack
- OpenCV
- Pandas
- Plotly

## 🚀 Menjalankan Aplikasi

Install seluruh dependensi:

```bash
pip install -r requirements.txt
```

Jalankan aplikasi:

```bash
streamlit run app.py
```
